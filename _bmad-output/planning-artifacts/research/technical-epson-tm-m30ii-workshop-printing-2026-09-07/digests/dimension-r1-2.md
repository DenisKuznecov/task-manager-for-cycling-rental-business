## Decision implication, gaps and next round

Direct browser LAN is a credible first prototype for Windows Chrome and user-reported working Wi-Fi. The cloud origin can deliver the app while browser-side code connects locally. Test HTTP ePOS with LNA and CORS, or supported Epson trusted-certificate setup; do not promise zero setup.

Unresolved: exact current SDK connect ports/transport and automatic certificate invocation; receipt endpoint actual CORS/preflight response; HTTPS endpoint configuration and self-signed alternative; installed firmware and ePOS enabled state. Epson HTML SDK pages and recent XML PDFs repeatedly returned fetch errors. Follow-up should target these sources only. No Safari/mobile conclusion needed. Six distinct sources, plus shared hardware evidence. Compatibility freshness target one month remains unmet by Epson's browser matrix; today's retrieval is not a new compatibility test.
